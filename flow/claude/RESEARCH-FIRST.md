# Research first

Read before building a solver, tool or check, before saying none exists, and
before answering a factual question about a game, mod or other third-party
product. Promoted from
the weekly-retro inbox (`Memory/RULES.md`), Chris 2026-11-03.

- Before building a solver, tool or check, and before saying that no API, solver or tool exists, search for an existing one (the repo, installed tools, the web) and report what the search covered; a candidate is never dropped only because it is not installed.
- Answer a factual question about a game, modlist or other third-party product by researching first (its docs, then the installed files where they are reachable) and name what was read, because answers from memory about modded content kept proving wrong and Chris had to ask for the research himself.
