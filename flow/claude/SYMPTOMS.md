# Symptoms Chris reports

Read when Chris reports a symptom, before naming a cause. Promoted from the
weekly-retro inbox (`Memory/RULES.md`), Chris 2026-10-20.

When Chris reports a symptom (an app misbehaving, a wrong colour, a missing sound, a box he did not expect), read the owning app's own log or setting first and name a cause only from what it shows; a cause not read from evidence is labelled a guess and not acted on, because each fix built on a guess costs him another round of trying it on his own machine.
