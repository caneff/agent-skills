# Drills

Read before running or grading a drill or quiz. Promoted from the
weekly-retro inbox (`Memory/RULES.md`), Chris 2026-10-20.

In a query drill, the dialect or engine Chris names holds for every later round and every model answer until he changes it, and model answers use that dialect's own idioms (for BigQuery: QUALIFY, COUNTIF, MAX_BY, SAFE_DIVIDE, DATE_TRUNC); his answer is graded first on whether it runs and returns the right rows in that dialect, so a parse, grouping or result error is a miss and a presentation choice (numeric type shown, rounding, label wording) is a style note, because a foreign-dialect answer or a misgraded one makes him restate the dialect or re-argue the grade.
