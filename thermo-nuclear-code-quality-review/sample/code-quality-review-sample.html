1Move the row layout into one module

Strong duplication csv_source.py:44 · json_source.py:51 · parquet_source.py:38 · manifest.py:120

Four files build the same comma-joined row layout by hand. Change the layout in one file and the other three still write the old shape. The manifest then fails to match the rows.

Before — layout copied in each source
parquet_source.py 
def write_row(self, r):
    line = ",".join([
        r.id, r.ts.isoformat(),
        r.amount, r.currency,
    ])
    self.out.write(line + "\n")
After — one layout, called everywhere
parquet_source.py 
from row_format import format_row

def write_row(self, r):
    self.out.write(format_row(r) + "\n")
  • One source of the row layout.
  • A new source gets the layout for free.
  • The manifest matches what the sources write.
CODING_STANDARDS.md: shared record shapes live in one module. Four hand-built copies break that rule.

2Keep one bad row from stopping the import

Blocker reliability importer.py:88

The importer reads all rows in one loop. One row that fails to parse raises, and the loop stops. The rows after it never load. A single bad row loses the whole file.

Before — one bad row stops the loop
importer.py 
for line in source:
    row = parse(line)      # raises on a bad row
    dest.write(row)
After — skip the bad row, keep the rest
importer.py 
for line in source:
    try:
        row = parse(line)
    except ParseError as e:
        rejects.append((line, e))
        continue
    dest.write(row)
  • One bad row no longer drops the file.
  • Rejected rows land in a list to review.
  • The good rows always load.
